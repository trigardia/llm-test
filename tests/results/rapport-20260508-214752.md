## Mission

Implémente un microservice Symfony 7 de scoring de risque transactionnel en temps réel pour une plateforme de paiement B2B traitant 5 000 transactions par seconde avec une latence p99 < 100ms.

La plateforme reçoit des demandes de paiement d'entreprises clientes. Chaque transaction est scorée en temps réel pour détecter les fraudes. Le score détermine si la transaction est : APPROVED, REVIEW_REQUIRED, ou BLOCKED. En cas de fraude détectée, un FraudAlertTriggered domain event est émis.

Contraintes : Symfony 7.2 + PHP 8.3 (readonly properties), Redis 7 (cache TTL par niveau de risque), PostgreSQL 16 (optimistic locking), RabbitMQ (domain events), CQRS + Event Sourcing, JWT RS256 (scope transactions:write, expiry 15min), rate limiting 1000 req/min par client_id.

class MLRiskScoringStrategy implements RiskScoringStrategy
{
    // [Performance] Circuit Breaker pattern. Timeout 50ms. Fallback to Heuristic.
    private bool $isClosed = true;
    private \DateTimeImmutable $lastFailure = new \DateTimeImmutable('-1 minute');
    private HeuristicRiskScoringStrategy $fallback;

    public function __construct(
        private \Symfony\Contracts\HttpClient\HttpClientInterface $httpClient,
        HeuristicRiskScoringStrategy $fallback
    ) { $this->fallback = $fallback; }

    public function score(Transaction $transaction): RiskScore
    {
        // [Circuit Breaker] Open if recent failures > threshold
        if (!$this->isClosed && (time() - $this->lastFailure->getTimestamp()) < 30) {
            return $this->fallback->score($transaction);
        }

        try {
            $response = $this->httpClient->request('POST', 'http://ml-scoring-service/api/score', [
                'body' => \json_encode(['amount' => $transaction->getMoney()->amountCents, 'client' => $transaction->clientId]),
                'timeout' => 0.05, // [Performance] 50ms hard limit
            ]);
            
            $data = $response->toArray();
            $score = new RiskScore((int)($data['score'] ?? 500));
            $this->isClosed = true; // Reset circuit
            return $score;
        } catch (\Exception $e) {
            $this->isClosed = false;
            $this->lastFailure = new \DateTimeImmutable();
            // [Fallback] Graceful degradation
            return $this->fallback->score($transaction);
        }
    }
}
